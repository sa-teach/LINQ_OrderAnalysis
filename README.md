# C_Sharp_LINQ_OrderAnalysis

## C#_LINQ_OrderAnalysis

### Задание «Контрольная точка №37 — LINQ-запросы к коллекциям»

Вариант 1. Анализ заказов
1. `List<Order>` (имя клиента, сумма, дата) минимум из 10 элементов, разных клиентов и дат.
2. Запрос: отфильтруйте заказы за определённый период, сгруппируйте по клиенту, посчитайте сумму заказов каждого клиента.
3. Отсортируйте клиентов по убыванию суммы.
4. Возьмите топ-3 клиента через `Take(3)`.
5. Выведите итоговую сводку: имя клиента и его суммарные траты.
